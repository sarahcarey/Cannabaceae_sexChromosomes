This repository contains items to recreate the figures and R-based analyses in Carey et al., 202X "An X-linked sex determination mechanism in cannabis and hop"

Please note that the files to generate the gene and repeat plots via GENESPACE (Figures 1c and 1d) are deposited on Zenodo 10.5281/zenodo.16326991. The deposited items are for the entire genome; to generate the plots as the R script has exactly, one will need to parse out the X and Y separately
