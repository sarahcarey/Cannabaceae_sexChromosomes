# This repository contains items to recreate the figures and R-based analyses in Carey et al., 2026 "An X-linked sex determination mechanism in cannabis and hop"

Please note that while many of the files to recreate the figures are within the figure_inputs directory,  the genome assembly and annotation files to generate some plots are instead deposited on Zenodo 10.5281/zenodo.16326991. The deposited items are for the entire genome; in some cases to generate the plots as the R script has exactly, one will need to parse out the X and Y separately

An additional note, the R script in it's current form has hard coded directory strings for input files. These will more than likely need to be adjusted in the script before use
